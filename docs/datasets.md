# Dataset protocol

Record accession, species, specimen, assay, anatomical scope, stage system, embryo/replicate identifiers, license and exact file hash. Keep biological replicates intact when splitting.

Developmental stages are ordinal within each study unless a published event-level mapping supports stronger alignment. Numeric mouse-day conversion is prohibited for non-mouse samples. Compare conserved events or cell-state trajectories and preserve uncertainty.

External measured data must be checked against current challenge rules. This benchmark can evaluate representations without making the source eligible for model training. Eligibility and biological comparability are separate fields.
